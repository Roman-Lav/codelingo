# CodeLingo — ТЗ

> Восстановлено по фактическому поведению версии 1.0.x (2026-11-08). Новые требования дописываются сюда до начала работы над фичей.

## Что это
Офлайн-тренажёр программирования для джунов в стиле 8-bit: короткие уроки из заданий по HTML, CSS, JavaScript, TypeScript, Python и SQL. Без сервера, без аккаунтов, весь прогресс хранится на устройстве.

## Платформы
| Платформа | Как запускается | Минимум |
|---|---|---|
| iPhone / iPad | Safari → «На экран Домой» (PWA) | iOS 15.4+ (оценка по используемым API; на реальном устройстве не проверялось) |
| Android | Chrome → «Установить приложение» (PWA) или APK/AAB через PWABuilder (TWA) | Android 9+, Chrome 109+ |
| Компьютер | Любой современный браузер; `dist/codelingo.html` открывается из файла | Chrome/Edge/Firefox/Safari последних 2 версий |

Ширина экрана от 320 px (iPhone SE) до планшетов и компьютера. Основная ориентация — портретная (manifest), но iOS её не фиксирует, поэтому альбомная тоже должна выглядеть корректно.

## Общие требования
- R1. Работает офлайн после первого запуска по https (service worker, cache-first). Каждое изменение файлов поднимает `VERSION` (app.js) и `CACHE` (sw.js) вместе.
- R2. Языки интерфейса и заданий: en, ru, uk, cs. Язык по умолчанию — язык системы, иначе en.
- R3. Темы: Авто / Светлая / Тёмная; `theme-color` обновляется вместе с темой.
- R4. Зона нажатия ≥ 44×44 px; нет горизонтальной прокрутки на 320 px; учтены safe area (вырез, home indicator).
- R5. Прогресс в `localStorage` (ключ `codelingo.v1`). Повреждённые или чужие данные при загрузке и импорте не ломают запуск (sanitize).
- R7. Раскладка (проверяет `tools/layout-check.py` на матрице: iPhone SE 1 320×568 … Pro Max 430×932, Android 360×800, iPhone в альбомной 852×393, iPad mini 744, iPad 820, десктоп 1280):
  - нет переполнения, обрезанного текста и наложения элементов;
  - кнопки и поля не заходят под вырез, home indicator и боковые вырезы в альбомной ориентации;
  - контент не прячется под панелью вкладок и футером урока;
  - панель вкладок выровнена по колонке контента (на широких экранах не растягивается на всю ширину);
  - от 700 px ширины — планшетная раскладка: колонка контента шире, курсы в 3 колонки; урок остаётся узкой колонкой для чтения;
  - подсказка маскота не закрывает текст вопроса и варианты ответа.
- R8. Каркас приложения: документ не прокручивается; высота каркаса = высота экрана (`100dvh`), прокручивается только область контента. Панель вкладок всегда прижата к нижнему краю экрана (с отступом под home indicator) и не сдвигается при переключении вкладок и при любой длине контента. Смена вкладки или экрана открывает новый экран с начала, без прыжков.
- R9. Типографика, минимализм: один системный шрифт для всего интерфейса; моноширинный — только внутри кода (блоки кода, поля ввода кода, блоки сборки, варианты-код). Три размера: заголовок 22 px, текст 17 px, подпись 13 px (код — отдельной настройкой S/M/L). Насыщенность только 400 и 600. Обычный регистр без разрядки; КАПС — только у главной кнопки урока («Проверить» / «Далее»). Никаких процентов и счётчиков, кроме цели дня и недели в профиле.
- R6. Поля ввода кода: шрифт ≥ 16 px (без зума в iOS), без автокоррекции; «умные» кавычки iOS нормализуются при проверке.

## Информационная архитектура (структура по образцу кабинета mate.academy, визуал свой)
Источник: публичное описание кабинета студента mate.academy (модули курса с прогрессом, статистика прогресса, сертификаты, мотивация). Календарь Q&A, вакансии, AI-интервью, чаты и менторы требуют сервера и остаются вне рамок.

| Вкладка | Аналог в mate.academy | Содержимое |
|---|---|---|
| **Учёба** | основной блок модулей курса с прогрессом | карточка «Продолжить» (курс + следующий урок, одна кнопка) → строка дневной цели → направления (курсы) с прогрессом «N из 10 уроков» |
| **Прогресс** (было «Профиль»: аккаунтов нет, слово вводит в заблуждение) | статистика прогресса + сертификаты | XP, серия, точность, неделя; прогресс по курсам; раздел «Сертификаты» — по карточке на каждый полностью пройденный курс с датой завершения |
| **Настройки** | — | без изменений |

Правила:
- IA1. Одна главная кнопка на экране «Учёба» — «Продолжить» (следующий непройденный урок последнего курса, где был прогресс; без прогресса — первый урок первого курса). После прохождения всех курсов карточка ведёт в «Прогресс → Сертификаты».
- IA2. На экране курса следующий доступный урок визуально выделен как «Следующий»; статусы уроков: пройден / следующий / закрыт.
- IA3. Сертификат появляется, когда пройдены все 10 уроков курса; дата завершения хранится в прогрессе (`prog[id].fin`, ISO-дата, проходит sanitize).
- IA4. Вкладок три, порядок: Учёба, Прогресс, Настройки. Переключение вкладок не меняет высоту и положение панели вкладок и шапки (экран не «прыгает»).

## Экраны

### 1. «Учиться» — список курсов
- 6 карточек курсов: тег и название (без чисел, процентов и полосы прогресса).
- Нажатие открывает экран курса.

### 2. Экран курса
- 10 уроков. Открыт первый урок и каждый следующий после пройденного; закрытые недоступны (замок).
- Кнопка «Назад» возвращает к списку курсов.

### 3. Урок
- 8 заданий четырёх типов: выбор варианта, заполнение пропуска, написание кода, сборка кода из блоков (в части заданий — с лишними блоками).
- Кнопка «Проверить» активна, только когда есть ответ; защищена от двойного нажатия (ответ не засчитывается дважды, быстрый второй тап не пропускает экран с ответом).
- Неверный ответ показывает правильный и возвращает задание в конец очереди.
- XP за задание: 10 — с первой попытки без подсказок, 5 — с подсказкой, 2 — после ошибки.
- Маскот-подсказка: убирает неверный вариант / показывает начало ответа / подсвечивает следующий блок / сообщает, что среди выбранных блоков есть неверный. Отключается в настройках.
- Панель символов над клавиатурой (`{ } < > ;` и т. п.): тап вставляет символ в позицию курсора, не закрывая клавиатуру; свайп по панели ничего не вставляет.
- Выход из урока после первого ответа — с подтверждением (до первого ответа — без вопроса). Незавершённый урок не отмечается пройденным и не даёт XP; данные ответов при этом уже учтены в точности (см. «Открытые вопросы»).
- Экран итога: маскот и «Урок пройден!» без чисел (XP по-прежнему начисляется и идёт в цель дня).

### 4. Прогресс (бывший «Профиль»)
- Сегодня: XP / дневная цель (полоса); отметки за последние 7 дней. Всего XP, серия дней и точность не показываются.
- По каждому курсу — одна строка: название слева, уровень словом справа, тонкая полоса под ними; без чисел. Уровень по внутреннему проценту знаний k (на экран не выводится): Не начат (0) / Новичок (<25) / Начальный (<50) / Джун (<75) / Уверенный (<100) / Мастер (100), k = `уроки_пройдено/всего × (0.5 + 0.5 × точность)`.

### 5. Настройки
- Тема, язык, звуки, подсказки маскота, анимации, размер кода (S/M/L), дневная цель (10/20/30/50 XP).
- Экспорт прогресса в JSON: через системное меню «Поделиться», где браузер умеет делиться файлами (iOS, Android, часть настольных), иначе скачивание файла; повторное нажатие во время открытого меню игнорируется, импорт из JSON, сброс прогресса с подтверждением.
- Версия приложения и пометка про офлайн-режим.

## Вне рамок
Аккаунты, синхронизация между устройствами, сервер, реклама, покупки, push-уведомления, выполнение настоящего кода (Pyodide/sql.js).

## Открытые вопросы
1. Публикация в App Store: нужен Apple Developer ($99/год) и Xcode; на этом Mac (macOS 13.2) свежий Xcode не ставится. Делаем только PWA для iOS? (сейчас — да)
2. Иконка 512 px помечена `any maskable`. На Android маскирующая обрезка может срезать края пиксель-арта; нужна отдельная maskable-иконка с полями ≥ 10%?
3. Публикация в Google Play через TWA (PWABuilder) нужна, или достаточно установки PWA из Chrome?
4. Прогресс живёт только на устройстве и пропадает при удалении иконки с iOS — достаточно ли ручного экспорта?
5. Ответы из брошенного урока сейчас учитываются в точности и проценте знаний. Учитывать только завершённые уроки?
6. Аппаратная/жестовая «Назад» на Android в установленной PWA/TWA закрывает приложение (нет обработки history). Нужно: урок → подтверждение выхода, курс → список курсов?
7. Лишние блоки есть только в 1 задании на сборку из 50. Добавить их в остальные задания?
8. При неудачном скачивании в standalone-режиме iOS (если меню «Поделиться» недоступно) пользователь не получает обратной связи. Нужен toast или текст JSON для копирования?
