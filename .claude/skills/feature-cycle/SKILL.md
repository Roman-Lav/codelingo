# Цикл фичи (экономный)

Цель: довести изменение до `PASS` у tester и отсутствия ❌/⚠️ у reviewer, не пересылая агентам лишний контекст.

## 1. Подготовка (сам, без агентов)
- Сверь запрос с `SPEC.md`. Если требование новое — допиши его в `SPEC.md` (1–3 строки), неясное — в «Открытые вопросы».
- Найди затронутые места через `grep -n`, не читай файлы целиком. `courses/*.js` — большие и однотипные: читай только нужный урок.
- Сформулируй для builder **конкретное ТЗ**: файлы, функции/строки, ожидаемое поведение, какие тесты добавить. Чем точнее промпт, тем меньше агент «исследует».

## 2. mobile-builder
Промпт: ТЗ из шага 1 + «трогай только эти файлы» + «подними версию `tools/bump-version.sh`» + «запусти `codelingo/tests/run.sh`, `tools/verify-build.sh` и, если менялись вёрстка/CSS/разметка, `python3 tools/layout-check.py` (скриншоты в `dist/layout/`)» + «ответ коротко: файл:строка, результат тестов, что не проверено».

## 3. mobile-tester и mobile-reviewer — параллельно
Запускай оба в одном сообщении (они независимы, reviewer ничего не меняет). Передавай им:
- список изменённых файлов (`git diff --stat` или ответ builder), а не пересказ кода;
- reviewer: «проверяй только изменения и связанные требования SPEC.md», не весь проект;
- tester: «прогони run.sh, добавь тесты на крайние случаи изменённой логики, отчёт — только проблемы».
- при изменениях UI: посмотри 2–3 скриншота из `dist/layout/` (узкий телефон, планшет, тёмная тема) по чек-листу скилла `design-critique`; цифры `layout-check` не видят визуальных проблем (например, перекрытие подсказкой).

## 4. Итерация
- FAIL / ❌ / ⚠️ → отправь builder **только список проблем** (файл:строка + ожидалось/получилось). Если агент ещё доступен — продолжай его через SendMessage вместо нового запуска (контекст уже есть).
- Мелкие ⚠️, которые владелец осознанно принимает, — запиши в `SPEC.md` → «Открытые вопросы» и не гоняй цикл.
- Максимум 3 итерации; дальше — остановись и спроси пользователя.

## 5. Готово
`codelingo/tests/run.sh` → PASS, `tools/verify-build.sh` → PASS, версия поднята. Коротко отчитайся пользователю.
